# Data sources and licences

Nothing in `data/raw/` is committed; `python data/download_data.py` fetches it.

| Data | Use | Source | Licence |
|---|---|---|---|
| `vehicles.mp4` (4K highway, 21 s) | live camera "highway-d1", speed / wrong-way / parking / ANPR, FPS benchmark | Roboflow `supervision` demo assets, https://media.roboflow.com/supervision/video-examples/vehicles.mp4 | provided by Roboflow as public demo material for the open-source `supervision` library; used here for demonstration only |
| `vehicles-2.mp4` (1080p city expressway, 42 s) | live camera "expressway-city", counting / classification | same, `vehicles-2.mp4` | same |
| License-plate detection dataset (6,176 / 1,765 / 882 images) | training and testing the plate detector | Hugging Face `keremberke/license-plate-object-detection` (originally Roboflow Universe, Augmented Startups) | CC BY 4.0 |
| OpenALPR benchmark, `endtoend/us` + `endtoend/eu` (330 images with plate box and text) | **evaluation only**: plate detection recall, OCR accuracy, preprocessing ablation | https://github.com/openalpr/benchmarks | repository under AGPL-3.0; images are not redistributed here |
| `data/scenarios/incidents.mp4` | **SIMULATED** wrong-way and illegal-parking test feed | generated by `data/make_scenarios.py` from `vehicles.mp4` (time-reversed segment + a car image pasted on the hard shoulder) | derived from the above |

Pretrained weights: YOLO11 (`yolo11s.pt`, `yolo11n.pt`) from Ultralytics, AGPL-3.0. `models/plate_yolo11n.pt` is fine-tuned
in this project (`models/train_plate_detector.py`). If you ship this commercially, check Ultralytics' licensing.
